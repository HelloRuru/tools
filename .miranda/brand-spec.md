# Readmoo Buy UI 規格

## 來源

- 品牌規範：`AGENTS.md`、`CLAUDE.md`、`DESIGN_SYSTEM.md`
- 既有頁面：`public/readmoo-buy/`
- 改良方向：保留日系文青計算機外觀，不重做版面

## 鎖定設定

- 字體：GenSenRounded，字重只用 400、500、700
- 主要裝飾：鼠尾草綠、淡金速查卡、計算機微旋轉、線條 SVG
- 淺色背景：暖白；深色背景：暖可可，禁止純黑與冷藍灰
- 圓角：8px、12px、24px；計算機外框保留 32px
- 陰影：沿用暖棕色陰影，不新增黑色陰影
- 互動：鍵盤焦點清楚、手機觸控至少 44px、尊重 reduced motion

## 本次不得出現

- 不新增三欄通用卡片版型
- 不新增 Emoji UI 圖示
- 不使用 `font-weight: 600`
- 不讓 380px 以下鍵盤改成三欄
- 不以低對比淺綠承載內文或白字按鈕
